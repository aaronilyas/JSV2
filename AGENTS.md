# AGENTS.md

Non-obvious conventions for this repo. Prefer the smallest correct change.

## Commands

Use these exact targets (do not invent alternatives):

- `make build` — compile `src/` to `dist/` with `tsc` (deps must already be installed)
- `make check` — `tsc --noEmit`
- `make wasm` — build `runtime/wasm/jsv.wasm` and copy `wasm_exec.js` from GOROOT
- `make test` — runs `make wasm`, then `cd runtime/go && go test ./...`, then `node --experimental-strip-types --test tests/*.ts tests/parser/*.ts tests/checker/*.ts tests/runtime/*.ts tests/mcp/*.ts tests/examples/*.ts`

## CLI

- Entry: `src/cli.ts` (tests spawn `node --experimental-strip-types src/cli.ts ...`)
- After build, `bin/jsv.js` imports `../dist/cli.js` and calls `main`
- `main` may return `number | Promise<number>`; the in-file entry guard and `bin/jsv.js` must `await` before `process.exit`
- Diagnostic JSON shape on stdout: `{ "ok": boolean, "diagnostics": Diagnostic[] }`
  - `ok` is true only when `diagnostics` is empty
  - `Diagnostic` is defined and exported from `src/diagnostics.ts`

## Layout

- Source: `src/`
- Tests: `tests/` (mirrors concerns; CLI coverage lives in `tests/cli.test.ts`; run/examples in `tests/examples/`)
- Do not edit `dist/` or `node_modules/`

## Parser

- Entry: `parse` from `src/parser/parse.ts` (hand-written recursive descent; no generator, no new deps)
- Semicolons are required (no ASI)
- Spans are 1-based inclusive (`SourcePosition` line/column; column counts UTF-16 code units)
- Primitive type names (`string`, `number`, `boolean`, `null`, `void`, `never`, `unknown`, `undefined`) are reserved keywords
- Checker: `checkSource` / `checkFile` from `src/checker/check.ts`
- `jsv check` parses then typechecks; parse errors skip the checker (no type diagnostics)

## Transpile / run

- Emitter: `src/transpile/emit.ts` — checked AST → plain ESM (types erased)
- Runner: `src/transpile/run.ts` — `runFile` / `loadModule`; writes temp `.mjs`, `import()`s in-process
- `jsv/dom` imports rewrite to an absolute file URL of `src/runtime` (or `dist/runtime` when built)
- Relative `.jsv` imports are emitted as relative temp-module imports; type-only names are dropped
- `jsv run` typechecks first; on diagnostics it prints like `jsv check` and does not execute

## Runtime

- Entry: `src/runtime/index.ts` (re-exports graph + DOM)
- Import specifier for `.jsv`: `jsv/dom` (ambient; see `src/checker/dom-lib.ts`)
- Signal graph / keyed diff / XML escape: Go sources in `runtime/go/`, compiled to WASM
- JS loads one WASM instance via `src/runtime/wasm-load.ts` (never spawn a Go process per call)
- `runtime/wasm/` is generated by `make wasm` and is gitignored
- DOM nodes / mount stay in `src/runtime/dom.ts` (JS applies patches)
- `renderToString` is on the `.jsv` surface; `mount` stays a host API

## MCP

- Entry: `src/mcp/server.ts` — run with `node --experimental-strip-types src/mcp/server.ts`
- Stdio MCP server name `jsv2`; stdout is MCP protocol only (no `console.log` on stdout)
- Tools: `check`, `typeOf`, `suggestFix`, `domAnalyze` (no completion / full LSP)
- DOM analysis (`src/mcp/dom-analyze.ts`) is pure AST; it must not import runtime/WASM modules
- Details: `docs/mcp.md`

## Git

Commit/push rules from the global `AGENTS.md` still apply. Do not commit secrets or generated artifacts. Humans merge.
